# 开放编码规则复查记录：P10–P12

## 复查结论

P10–P12 编码完成后，中文开放编码规则继续保持 v0.3，不升级到 v0.4。

原因是本批没有出现 v0.3 无法表示的新证据性质：

- P10 的具体任务、事件后自报、一般时间使用方式和假设记录可以分别使用 `E`、`R`、`H`；
- P11 的两个不同事件可以使用 `E01`、`E02` 分开追踪；
- P12 缺少单次事件锚点的反复行为可以使用 `R`，对记录方式的预期可以使用 `H`；
- 本批没有出现需要新增 `G` 以外引导类别的材料；
- 单一证据性质规则足以处理事实、自报与一般经验的拆分。

## 核查项目

| 核查项 | 结果 | 说明 |
|---|---|---|
| 具体事件最低条件 | 通过 | P10-E01、P11-E01、P11-E02均具有单次情境锚点，且任务、变化、行动或结果至少支持三项。 |
| 一般经验边界 | 通过 | P12没有被强行包装为单次事件。 |
| 单一证据性质 | 通过 | 表中不存在“真实事件与一般经验”等混合类型。 |
| 假设与实际使用 | 通过 | P10的软件进度属于实际使用；设想留下记录另列为H。 |
| 多事件区分 | 通过 | P11的评分任务与困难阅读使用不同事件编号。 |
| 自报边界 | 通过 | 状态、记忆表现、情绪和效率均保留为参与者自报。 |
| 反例保留 | 通过 | P11同时保留任务切换可能有效与多次切换仍失败。 |
| 新编号需要 | 不需要 | E、R、C、H、G足以覆盖本批材料。 |

## 决定

1. 不为了形式上的版本递增增加新规则。
2. P13–P14 继续使用 v0.3。
3. 完成全部14位参与者后，进行一次全语料编号、证据类型、时间戳和重复编码审计。
4. 全语料审计完成前，不进入聚焦编码和主题生成。
