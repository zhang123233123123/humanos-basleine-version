# HumanOS 访谈聚焦编码框架 v0.1

## 1. 当前阶段

本框架用于把93条开放编码记录中的286个材料贴近型初始标签组织成较稳定的聚焦类别。聚焦类别用于比较案例和减少同义表达，但它们不是最终主题，也不表示因果关系、普遍规律或系统效果。

本框架从中文开放编码表归纳形成，暂不使用 JITAI 预设类别。JITAI 只能在主题形成和审查之后作为理论解释框架介入。

## 2. 映射原则

1. 每条开放编码记录至少映射一个、最多映射三个聚焦类别。
2. 聚焦类别必须能够追溯到参与者、记录编号、时间戳和原始中文编码。
3. `真实事件`、`一般经验`、`假设性回答`和`强引导回答`是独立证据属性，不因进入同一类别而变成同等证据。
4. 同一初始标签只有在意义相近时才合并；文字相似但作用不同的标签保持分开。
5. 聚焦类别允许同时包含正例和反例。例如“返回与重新定向”同时保留返回困难和直接继续。
6. 类别覆盖记录数只能用于描述材料分布，不能直接决定主题重要性。

## 3. 聚焦类别

### FC01 计划承诺与时间预期

**定义：** 参与者如何表示任务目标、预计时长、数量、截止时间、阶段和完成标准。

**纳入：** 计划任务数量、阶段持续时间、预计工作量、计划开始时间、完成比例目标。

**排除：** 计划失效后的重新安排归入 FC07；单纯记录停止位置归入 FC08 或 FC09。

**开放编码示例：** `为词汇任务设定30分钟`、`为阶段预估持续时间`、`周末安排六小时学习`。

### FC02 外部条件与资源约束

**定义：** 任务之外的事件、基础设施、人员、地点、时间窗口或资源改变任务可行性。

**纳入：** 家庭事务、网络、导师可用性、设备预约、天气、会议冲突、营业时间和后续事务。

**排除：** 任务本身失败或难度变化归入 FC04；参与者状态归入 FC03。

**开放编码示例：** `网络访问中断`、`导师不在导致讨论延期`、`其他事务占用白天时间`。

### FC03 参与者自报状态

**定义：** 参与者明确报告的身体、注意、情绪、疲劳、兴趣或主观能力状态。

**纳入：** 疼痛、困倦、烦躁、眼睛疲劳、注意力下降、兴趣降低、主观记忆表现。

**排除：** 未经参与者明确报告的心理诊断；任务结果或设备状态。

**开放编码示例：** `自报身体疼痛严重`、`接待后身体疲劳`、`阅读兴趣下降`。

### FC04 任务状态、难度与反馈

**定义：** 任务内部的进展、失败、结果质量、难度或正负反馈改变下一步可行性。

**纳入：** 样品或数据未达预期、找不到方法、软件学习受阻、实际表现低于计划、读后难度判断变化。

**排除：** 纯外部资源不可用归入 FC02；参与者对结果产生的情绪归入 FC03。

**开放编码示例：** `样品质量未达预期`、`持续失败后感到烦躁`中的失败部分、`实际完成50个新词`。

### FC05 启动、继续、暂停与停止决定

**定义：** 参与者决定是否开始、继续、暂停、放下或放弃当前任务。

**纳入：** 未开始、强迫继续、做到无法继续才停、延长当前任务、停止当天工作、达到当日努力上限。

**排除：** 切换到哪个替代任务归入 FC06；停止后如何重排归入 FC07。

**开放编码示例：** `晚间学习未开始`、`继续完成剩余单词`、`停止当天剩余工作`。

### FC06 任务切换与替代活动

**定义：** 从原任务转向另一项任务、休息、娱乐或其他活动，以及切换是否支持继续。

**纳入：** 写作转刷题、困难任务转偏好任务、连续切换多个科目、用阅读替代实验、切换后仍失败。

**排除：** 仅调整同一任务的未来时间归入 FC07；返回原任务归入 FC10。

**开放编码示例：** `从写作切换到刷题`、`切换到偏好任务`、`多次任务切换后仍可能失败`。

### FC07 计划修复、依赖与下游传播

**定义：** 原安排失效后，任务如何顺延、重新分配、阶段回退或影响其他任务。

**纳入：** 顺延至次日/下周、重建计划、串行依赖、压缩后续阶段、按剩余工作量和截止时间调整。

**排除：** 计划最初如何制定归入 FC01；只描述暂停动作归入 FC05。

**开放编码示例：** `延期向后续任务传播`、`以新计划替代旧计划`、`讨论后返回前序实验阶段`。

### FC08 既有任务痕迹与材料定位

**定义：** 在没有额外反思表单的情况下，软件、文本、标记、文件夹或既有成果保留了任务状态。

**纳入：** 软件进度、页码题号、文本内容、计算结果、文件夹、讨论记录和颜色标记。

**排除：** 访谈者要求设想的新记录归入 FC09；利用痕迹返回的动作同时可归入 FC10。

**开放编码示例：** `软件保留词汇学习进度`、`可见计算结果保留进度`、`通过项目文件夹定位材料`。

### FC09 主动记录、检查点与反思内容

**定义：** 参与者实际记录或设想记录的进度、下一步、材料、推理、原因和关键内容。

**纳入：** 停止位置、下一行动、已尝试路线、问题、关键观点、次日步骤、中断原因。

**排除：** 已自然存在的任务痕迹归入 FC08；对记录负担、隐私或负面影响的担忧归入 FC11。

**开放编码示例：** `记录任务所处阶段`、`设想记录已探索路线`、`设想记录下一步行动`。

### FC10 返回、重新定向与恢复结果

**定义：** 返回原任务时采取的行动、所需时间、主观困难和最终是否能够继续。

**纳入：** 直接返回、重读、查看记录、重新梳理、遗忘先前状态、返回耗时、返回后仍无法继续。

**排除：** 是否决定停止归入 FC05；用于支持返回的材料本身归入 FC08/FC09。

**开放编码示例：** `直接返回积压任务`、`返回需要10至15分钟`、`任务衔接困难`。

### FC11 记录与支持的负担、隐私和控制边界

**定义：** 参与者对记录、反思、提示或信息保存可能造成的额外工作、情绪影响、隐私风险或控制损失的边界表达。

**纳入：** 不愿记录负面原因、担心被他人看到、完整反思耗时、只愿记录最少内容。

**排除：** 单纯没有恢复困难归入 FC12；目标人群质疑归入 FC13。

**开放编码示例：** `担心重看负面原因影响情绪`、`认为完整反思耗时`、`不书面记录私人决心`。

### FC12 自我充足、自然边界与低恢复需求

**定义：** 参与者通过自然任务边界、既有结构或个人策略直接继续，并明确呈现较低额外支持需求。

**纳入：** 在计算步骤完成后休息、写作框架预先确定、无显式恢复准备、通常可顺畅返回。

**排除：** 因隐私或负担拒绝记录归入 FC11；没有核心事件但涉及抽样批评归入 FC13。

**开放编码示例：** `正常休息恢复阻力低`、`无显式恢复准备`、`暂停后沿原框架继续`。

### FC13 研究范围、协议与目标人群边界

**定义：** 材料不符合核心任务中断范围、受到强访谈引导，或参与者明确质疑研究对象与使用场景。

**纳入：** 非学习社交事件、没有核心失败事件、强引导作业情境、目标人群建议和长线科研场景差异。

**排除：** 仅仅报告低恢复困难归入 FC12；普通假设性功能偏好仍按其内容映射其他类别并保留 `H` 属性。

**开放编码示例：** `自报未遇到核心问题`、`质疑当前研究对象匹配`、`确认访谈者提供的作业中断情境`。

## 4. 多类别映射边界

一条记录可以有多个聚焦类别，但必须表示片段中并列存在的不同分析成分。例如：

- “网络中断后寻找咖啡馆继续部分写作”可以映射 FC02、FC05；
- “软件保存进度，因此返回时直接继续”可以映射 FC08、FC10、FC12；
- “疼痛使实验不安全，改做阅读并把实验移到晚上”可以映射 FC03、FC06、FC07。

不得因为一条记录与某个未来主题看起来相关，就在缺少开放编码依据时追加类别。

## 5. 下一步映射表字段

下一步逐条映射93条记录，至少保留：

| 字段 | 用途 |
|---|---|
| 参与者编号 | 保留案例来源 |
| 记录编号 | 连接开放编码表 |
| 时间戳 | 返回逐字稿 |
| 证据类型 | 保留证据性质差异 |
| 初始编码 | 保留原始中文标签 |
| 主聚焦类别 | 当前片段的中心作用 |
| 次聚焦类别 | 最多两个必要的并列作用 |
| 映射备忘录 | 解释纳入、排除和不确定性 |

框架将在93条记录全部映射并检查反例之后修订；在此之前不形成最终主题。
